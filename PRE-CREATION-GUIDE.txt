BEFORE SETUP

Verify Tails and the pinned Bitcoin Core archive independently:
https://tails.net/install/download/
https://bitcoincore.org/en/download/#verify-your-download

Put bitcoin-32.0rc2-x86_64-linux-gnu.tar.gz beside this project folder.
Prepare secure persistent/offline wallet storage. Close other Core instances.

Run sh tails.sh create to create the wallet and export its public key.
Back up descriptor-signer-wallets/ before shutting down Tails.

Whenever ready, run sh tails.sh import, select that wallet, and paste the
coordinator's PUBLIC descriptor. See README.md for setup and recovery.
